# Accessibility Verification

Target: WCAG 2.2 AA-aligned product behavior and platform-native accessibility APIs. This is an engineering target, not a legal certification.

- [ ] Entire manager flow works with keyboard only on web.
- [ ] Interactive controls expose names, roles, and disabled/selected state.
- [ ] Screen reader announces the “HoleFilled” success result.
- [ ] Status never depends on color alone.
- [ ] Text can scale to 200% without lost content or functionality.
- [ ] Touch targets are at least 44 by 44 logical pixels.
- [ ] Focus indicator is visible and focus order follows reading order.
- [ ] Error messages identify the affected field and recovery action.
- [ ] Motion respects reduced-motion preferences.
- [ ] Contrast is manually checked against WCAG 2.2 AA thresholds.
- [ ] Android TalkBack, iOS VoiceOver, and a desktop screen reader receive manual smoke tests before release.
