Support

HoleFilled is currently a RevenueCat Shipaton 2026 preview. It uses fictional demonstration data and is not yet a live employer staffing service.

Before reporting a problem

  • Confirm that the device has an internet connection.
  • Restart the preview application.
  • For purchase issues, use Restore Purchases and verify the same store account is signed in.
  • Never include passwords, payment-card information, real employee records, or sensitive health information in a report.

Report an issue

Open a public technical issue in the HoleFilled GitHub repository. Do not use public GitHub issues for private or personal information.

Account and privacy requests

A dedicated private support email must be added before production launch. Until then, the preview should not be used with real personal data or production accounts.

Emergency notice

HoleFilled is not an emergency service. Contact the employer or local emergency services directly when immediate assistance is required.
